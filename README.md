# UiPath Email Extractor using Regex

## Overview

This UiPath automation extracts all email addresses from a text file using Regular Expressions (Regex).

## Input

A text file containing employee information and email addresses.

## Process

1. Read the contents of the text file.
2. Use a Regular Expression pattern to identify email addresses.
3. Store all matches in a collection.
4. Loop through the collection.
5. Display each extracted email address in the Output panel.

## Activities Used

- Read Text File
- Find Matching Patterns (Regex)
- For Each
- Log Message

## Skills Demonstrated

- Regular Expressions (Regex)
- String Processing
- Collections
- Loops
- File Handling
